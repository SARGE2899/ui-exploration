# UI Exploration — Understanding Interfaces

A simple, interactive playground to understand how UI components behave in real products.

This is not a design system or a component library.  
It is a hands-on way to **see, click, and understand** common UI patterns used in modern applications.

---

## What this covers

- Buttons (primary, secondary, destructive, icon)
- Forms (inputs, dropdowns, validation, toggles, sliders)
- Media (images, avatars, thumbnails, video)
- Navigation (navbar, breadcrumbs, pagination, sidebar, segmented control)

Each component is:
- Explained in plain language  
- Interactive (click / type / toggle)  
- Built to reflect real product behavior  

---

## Why this exists

Most people learn UI by looking at static designs.

This project focuses on:
- how components behave  
- how users interact with them  
- why certain patterns exist  

Built to bridge the gap between:
> "I know what this looks like"  
and  
> "I understand how this works in a product"

---

## Tech

- HTML
- CSS
- Vanilla JavaScript

No frameworks. No libraries.  
Everything is built from scratch to keep it simple and transparent.
